## Graphite v1.0.0

Портативный редактор текста и заметок для Windows 10 / 11 (`Блюр` / `Обычный` стиль окна, вкладки, кастомные шрифты, кодировки и 15 языков интерфейса).

### Что внутри архива `Graphite-Portable-Windows.zip`
- `Graphite.exe` — нативная портативная версия для Windows 10 / 11 (x64, без установки, сохраняет все данные в папку `PortableData` рядом с `.exe`).
- `Graphite.html` — автономная веб-версия в одном файле (открывается в любом браузере без интернета).
- `README-RU-EN.txt` — краткая справка по запуску.

### Основные возможности v1.0.0
- Вкладки, папки, закрепление заметок, корзина и поиск с заменой (`Ctrl+F`).
- Режимы: форматированный текст, чистый текст / код с номерами строк и предпросмотр Markdown.
- Кодировки `UTF-8`, `UTF-8 BOM`, `UTF-16 LE/BE`, `Windows-1251` и прямое сохранение открытых файлов по `Ctrl+S`.
- Подключение своих шрифтов (`.ttf`, `.otf`, `.woff`, `.woff2`) и системных шрифтов по названию.
- 8 сменных иконок приложения и создание ярлыка на Рабочем столе.
- Автоматическое определение языка строго по языку интерфейса Windows (без учёта региона) + 15 языков на выбор.
- Опциональная установка в качестве замены стандартного Блокнота Windows с откатом в один клик.

### Примечание Windows SmartScreen
Так как `.exe` не подписан платным коммерческим сертификатом EV Code Signing, при первом запуске Windows SmartScreen может показать синее окно предупреждения: нажмите **«Подробнее» -> «Выполнить в любом случае»** (*More info -> Run anyway*).
